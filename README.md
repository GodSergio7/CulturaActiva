# 🎭 CulturaActiva

**CulturaActiva** es una plataforma web diseñada para la gestión y difusión de eventos culturales locales (conciertos, teatro, talleres...). Este proyecto forma parte del módulo **Proyecto Intermodular** del ciclo **DAW** (Desarrollo de Aplicaciones Web).

## 🚀 Funcionalidades

El proyecto funciona como una **SPA (Single Page Application)** simulada, utilizando almacenamiento local para la persistencia de datos.

* **Página Principal (Pública):**
    * Listado dinámico de eventos.
    * Buscador en tiempo real y filtrado por categorías.
* **Panel de Administración (Privado):**
    * **CRUD Completo:** Crear, Leer, Editar y Borrar eventos.
    * Gestión de estados (Activo, Borrador, Cancelado).
    * Simulación de Login (Usuarios: `admin@cultura.com` / `user@cultura.com`).
* **Persistencia:** Uso de `localStorage` para guardar eventos y sesiones sin necesidad de base de datos externa por el momento.
* **Diseño Responsive:** Adaptado a Móvil, Tablet y Escritorio.

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico**: Estructura limpia y accesible.
* **CSS3 Moderno**: Flexbox, Variables CSS y Diseño Responsivo.
* **JavaScript (Vanilla)**: Manipulación del DOM, Arrays (ES6+), LocalStorage.
* **Git & GitHub**: Control de versiones.

## 📂 Estructura del Proyecto

El desarrollo se ha dividido en 3 Retos principales:
1.  **Reto 1:** Análisis, documentación y prototipado (Mockups).
2.  **Reto 2:** Diseño de Base de Datos (SQL) y Maquetación Web.
3.  **Reto 3:** Lógica de programación en JS y sistema CRUD.
